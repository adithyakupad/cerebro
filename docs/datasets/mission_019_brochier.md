# Mission 019: native Brochier acquisition and eligibility audit

**Source:** Brochier et al., *Scientific Data* 5:180055 (2018), [paper](https://pmc.ncbi.nlm.nih.gov/articles/PMC5892370/); publisher-authorized [GIN data DOI 10.12751/g-node.f83565](https://doi.org/10.12751/g-node.f83565). This supersedes the access status in the historical Mission 018 audit without editing it. The DOI ZIP was acquired through official public HTTP byte ranges; no access controls were bypassed. The [GIN CLI](https://github.com/G-Node/gin-cli/wiki/Help) also documents repository/content retrieval, but it was not installed or needed here. Exact archive URL, 15,496,411,668-byte size, observed ETag, member offsets, sizes, ZIP CRC32 and full-file SHA-256 are in [the asset manifest](mission_019_brochier_assets.json). `python -m tools.fetch_brochier <member names>` can reproduce selected assets from this manifest into ignored `data/raw/brochier/`; it verifies revision, member name, CRC, size and SHA-256. The source README, licenses, two odML metadata files, CCF array maps, sorted NEVs, NS2 sensor/LFP streams and native raw NS5/NS6 streams were retained locally without alteration. Raw files are excluded from Git.

These intervals come from the complete native NSx sample-block headers and verified file lengths, **not spike extrema**. Each selected raw stream has one contiguous sampled block and no declared missing block within it. N's raw stream starts 82 native ticks (2.733 ms) after the NEV clock origin. NS2 is present at 1 kHz for both recordings, but L NS2 has six analog sensor channels whereas N NS2 has 102 channels (96 LFP plus six sensors). The odML identifies grip-force channels 137–140, load force 141, and displacement 143, sampled on the shared time base. Their recorded voltage scale is available; a cross-animal conversion into common calibrated physical force/displacement units was **not established**, so continuous regression remains ineligible. There is no verified hand trajectory. The task labels encode instructed grip and load, not measured continuous movement.

The source odML and sorted NEV share 30 kHz event ticks. All 135 L and 142 N correct-trial windows `[GO-ON, GO-ON+280 ms)` fit inside sampled raw neural blocks; no window was inferred from silence between spikes. Sorted NEV rows include noise and multi-unit entries, so the analysis uses only odML-designated SUA IDs. Neither channel numbers nor SUA indices represent cross-animal neuron identity. The four shared labels and repetitions support a bounded condition-classification case study and descriptive condition-matched population work. They do not support general subject-invariance claims because each animal contributes one session and subject is fully confounded with date, array, and session. The [native audit JSON](../../reports/mission_019_brochier_native.json) records verified hashes, counts, clock rates and coverage.

**Source discrepancies and reuse caution.** The primary paper summarizes N as 160 total/141 correct trials; native odML and task settings list 161/142. No authoritative explanation was found, and the analysis preserves all native correct trials rather than guessing which one to remove. The ZIP root license and dataset README describe CC-BY-4.0, while `datasets/LICENSE.txt` contains CC-BY-SA-4.0 legal text. The original files are kept locally; redistribution of raw assets or their adapted derivatives needs publisher clarification of the intended dataset license. The committed small aggregate reports include source attribution and checksums.

Eligibility: discrete four-condition classification **PASS for a two-animal case study**; condition-matched population description **PASS with limited biological generalization**; calibrated continuous movement/force regression **INCONCLUSIVE**; general cross-subject representation transfer **INCONCLUSIVE**.
