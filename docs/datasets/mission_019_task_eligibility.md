# Mission 019: task-specific cross-subject eligibility

Status is about a *specified question*, not a blanket property of a corpus. Every task requires authentic neural data, source identity and reuse terms, observation coverage from recorded samples or authoritative acquisition metadata, explicit biological subject/session IDs, valid clocks and trial boundaries, a neural feature policy that does not equate neurons across animals, and train/evaluation isolation. Spike extrema never certify neural coverage. A two-subject result is a two-animal case study, not population evidence for subject invariance.

| Question | Essential beyond the common gate | Desirable, but not a gate | Claim limit |
|---|---|---|---|
| Continuous movement or EMG regression | Same measured physical target and units across animals; synchronized samples; traceable calibration and preprocessing; train-only fitted transforms; prespecified causal/offline timing and matched target support | Raw broadband, repeated sessions/subjects, direct physical calibration trace | Author-preprocessed EMG can be analyzed *exploratorily* with explicit leakage caveat, never called independently split-safe. |
| Discrete movement/task-condition classification | Source-recorded label semantics shared across subjects; event timing and adequate class repetitions; trial-level held-out evaluation; class-prior control | Task-cue control for a motor-specific claim; continuous behavior calibration, raw EMG, identical neural units | Instructed object/grip class is a task label, not continuous movement or EMG decoding. Without a cue control, condition-label classification cannot be attributed specifically to movement activity. Sensor calibration is irrelevant unless deriving the label from sensors. |
| Population representation comparison | Coverage-verified simultaneous populations; comparable task epoch/condition or explicit distribution-only estimand; unit-count/rate/sampling controls; subject/session strata and uncertainty at the correct independent level | Physical behavioral calibration, neuron identity, multiple sessions per subject | Descriptive similarity or separability is not neural identity, causal connectivity or transfer. |
| Cross-subject neural representation transfer | Held-out biological subject; prespecified source/target partition and information budgets; compatible input/label or self-supervised objective; no assumed unit ordering; training-only representation/scaler/model selection; independent evaluation | Multiple held-out subjects/tasks and sessions per subject | One target animal gives a bounded transfer case study, not a validated general subject-invariant representation. |
