# Mission 017 cross-subject eligibility screen

Screened before any Mission 017 cross-subject model outcome. **No corpus currently passes every strict gate.** Rankings indicate the most useful *next audit*, not permission to fit a model. Real neural observation intervals must be certified from sampled acquisition or authoritative recording metadata; spike endpoints do not suffice. Raw behavioral targets or a reproducible transform fit only on training data are required. Independent sorted units are never assigned a common ordering across animals.

The source ranking weighs usable original behavior, repeated animals, and the plausibility of verifying neural coverage. It does **not** use favorable decoder scores. Indy/Loco has the most sessions and explicit behavioral units, but its missing Loco coverage is decisive under the existing policy. Brochier provides stronger published raw neural provenance but currently lacks a directly verified asset/license audit and has only one session per subject. No prospective cross-subject protocol or new transfer run was justified in this mission. See the [cross-subject report](../../reports/mission_017_cross_subject.md).

Exact native asset checksums and dataset-specific reuse terms for Brochier and DANDI 000947 were **not established** by this source-document review; public accessibility and a paper's license do not substitute for those checks. Their neural coverage and target definitions must be confirmed from selected native sessions, not inferred from abstract-level descriptions. The table records these unknowns as eligibility failures rather than filling them with assumptions.
