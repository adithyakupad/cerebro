# Mission 016 dataset eligibility, before model selection

This screen uses source metadata and existing native audits, not decoder scores. A recording is eligible for a particular claim only after its exact asset checksum, neural observation coverage, target provenance, subject/session identity and license are established. Previously inspected evaluation outcomes cannot be used to select a new method. The rules and decisions below precede any Mission 016 experiment.

All three candidate bytes were subsequently downloaded to Git-ignored `data/raw/link/` and matched their published SHA256 checksums. `cerebro.link.load_link` verified 375 chronological, nonoverlapping CO trial references per date; matching neural/behavioral reference slices and timestamps; 96 nonnegative integer crossing columns; finite two-dimensional normalized flexion position/velocity; and exact source-contact key correspondence. Referenced neural sample totals are 26,582 (February 6), 26,675 (February 11), and 25,547 (February 22), with 23 target positions per date. These **pass the sampled-coverage and task/target gates for a qualified same-subject study**, while intersample raw-voltage continuity and individual neuron identity remain unknown. Source January 27 trials have run ID 3, whereas new target trials have run ID 2; the [authors' format description](https://github.com/chesteklab/LINK_dataset) identifies run ID as within-day session order, not a target-style code. All four dates are CO, but date, run and session effects cannot be separated causally. The pinned manifests are `configs/link_20200206.json`, `configs/link_20200211.json`, and `configs/link_20200222.json`.
