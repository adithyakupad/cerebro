# Mission 018: Brochier native-data eligibility audit

**Decision: INCONCLUSIVE for native integrity; FAIL for a strict cross-animal decoding run at this revision.** This is a source-document audit, not a native-file inspection. No Brochier recording was downloaded, no source-file checksum was measured, and no model was fit. Source paper: [Brochier et al., Scientific Data 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5892370/); publisher-authorized [G-Node dataset DOI 10.12751/g-node.f83565](https://doi.gin.g-node.org/10.12751/g-node.f83565/). The dataset DOI states CC-BY-4.0, publication date 2017-12-28, and a 14 GiB ZIP. Cite the dataset separately from the article.

## Native assets and scope

The paper's Table 3 identifies one session per animal: Monkey L `l101210-001` (204 trials, 135 correct) and Monkey N `i140703-001` (160 trials, 141 correct). Listed files are L `.ccf`, `.nev`, `.ns2`, `.ns5`, `.odml`, sorted `l101210-001-02.nev`; N `.ccf`, `.nev`, `.ns2`, `.ns6`, `.odml`, sorted `i140703-001-03.nev`. These are published names, **not verified local assets**. Exact byte sizes, immutable per-file identities, SHA-256 values, complete acquisition starts/stops, gaps, and corruption checks remain unknown; see [machine manifest](mission_018_brochier_assets.json). Preserve these original files in ignored `data/raw/` if obtained later.

The paper documents 10×10 Utah arrays in contralateral motor cortex, 30 kHz extracellular acquisition, 1 kHz analog streams, event codes, and offline spike sorting. It reports L 93 single-unit/49 multi-unit rows and N 156/19. These are sorted units, not homologous neurons or ordered features across animals. The two subjects have different electrode positions/orientations; the source paper's anatomy must govern any exact region label. One session per animal makes subject, session, date, array and recording conditions inseparable.

The `.ns2` stream contains object grip/load force-sensitive-resistor and Hall-effect displacement signals; it is **not a continuous hand or cursor trajectory**. The paper reports digitization near 0.15 mV/bit and approximate displacement range 4–14 mm, but this does not establish a common calibrated physical force or position target across animals. Original analog samples and calibration metadata must be inspected before choosing a regression target or normalization. Four instructed grip×load conditions exist (SG-LF, SG-HF, PG-LF, PG-HF), but task labels alone are not measured kinematics.

The `.nev` events and analog channels share an NSP clock according to the paper. The N `.ns6` stream begins 82 neural samples after `.ns2`/`.nev` (about 2.73 ms); LFP filtering adds about 3.6 ms. Sorted-spike waveform timestamps and offline sensor-derived events have separate timing conventions. The paper describes eight sensor events derived offline and manually corrected; object touch/displacement online estimates were not saved as continuous hand motion. Native headers, sample blocks, gaps, event codes and sensor alignment must be checked with the published Neo `BlackrockIO`/`ReachGraspIO` approach before binning or assigning observation masks. Spike extrema cannot prove continuous coverage.

## Access and independent review

On 2026-10-15, the browser-readable dataset DOI and primary paper were accessible. The GIN repository browse/archive returned HTTP 403 through the web tool; a direct request for the L `.odml` file timed out after 20 seconds from the local host, and a read-only GIN Git probe did not return before it was stopped after 30 seconds. Therefore neither native contents nor exact checksums were obtained. These failures describe **this execution environment**, not the repository's general public availability. The dataset DOI's CC-BY-4.0 statement supports reuse with attribution; it does not certify a particular unexamined file's integrity.

Independent scientific review of the primary paper confirmed the two-session confound, left-hand task in both animals, the sensor-versus-kinematic distinction, and the nominal condition counts. The review did not inspect native bytes. [Eligibility and timing gates](../../reports/mission_018_eligibility.md) specify what remains before a prospectively frozen transfer protocol can be justified.
