## Models, decomposition and information budgets

Reuse existing Ridge/StandardScaler, flatten, LINK loading, trial-loss and block-resampling infrastructure. Evaluate frozen source, source mean, B-label calibration mean, intercept-only frozen-source correction, direct ridge, source-assisted residual ridge, and source/direct or source/residual convex shrinkage at weights0.1/0.25/0.5. All primary decoders use source scaling; the B-fitted scale is diagnostic only. Source-assisted methods transfer fitted source weights. No new model family, architecture, target normalization or anatomical mapping is introduced.

Allocation is independent of outcomes: chronological uses firstB pool rows; uniform uses a fixed seeded subset; balanced first randomly orders trials within each command stratum, then cycles a fixed seeded condition order taking one remaining row per stratum until B, sorts selected rows chronologically, and never duplicates a trial. B smaller than available conditions cannot cover every condition. Record exact IDs for all draws. Budget B counts complete position-labeled trials; commanded labels and unlabeled neural access are recorded separately. No method pools evaluation or test data into training. Native targets are not normalized using evaluation observations.

For each unit/coordinate, convert fitted coefficients to a common raw-count frame before measuring squared coefficient dispersion across calibration subsets. Prediction ensemble mean and across-subset variance are computed pointwise on fixed evaluation bins, then averaged **equally across trials**. The empirical identity is average subset MSE = MSE(ensemble mean) + mean across-subset prediction variance (population denominator, ddof0). The first term includes noise and model mismatch; it is not an identified physiological bias. Also decompose each trial's MSE into squared mean residual offset plus centered time-varying residual MSE. Calibration mean is a genuinely label-only control; intercept-only frozen correction still uses frozen neural predictions and is labeled accordingly.

## Selection and null rule

Primary development budget is15. Prespecified promotion candidates, in order of increasing departure from frozen source: direct-shrink0.1, residual-shrink0.1, direct-shrink0.25, residual-shrink0.25, direct-shrink0.5, residual-shrink0.5, direct ridge at alpha×100. These candidates use **chronological first15 position labels**, no target command labels and source scaling. Allocation/scaling/low-alpha experiments diagnose mechanisms and cannot silently become unregistered promotion candidates.

Promote the **first** candidate meeting all requirements, rather than the best score: (a) equal-date mean relative MSE reduction≥5% versus both frozen source and original direct15; (b) strictly lower MSE than both on each of the three development dates; (c) conditional 95% moving-five-trial-block interval for equal-date mean paired MSE differences lies below zero against both controls. Bootstrap within sessions, never relabel draws as biological replication. This strict development gate is evidence to justify independent validation, not proof of efficacy. If no candidate passes, publish the negative development diagnosis and do **not** promote or test a mitigation on untouched data. A failed gate does not justify enlarging the candidate set, changing the threshold, selecting favorable seeds or revisiting inspected test sets.

## Independent validation gate

Metadata-only inventory will identify the first three previously uninspected compatible CO sessions chronologically after Feb22, selected by date/identity, never model score. Before any model outcome on these sessions, pin assets and audit native coverage, clock/trial references, subject, contact ordering, target compatibility and access history. If a mitigation passes development, commit a separate immutable validation addendum specifying these exact assets and the selected fixed method. Source remains Jan27first300. Target calibration pool is first75 and labeled first5/15/30 (15 primary); evaluation is originalrows75:375. Evaluate frozen, direct, residual, source mean, calibration mean and selected mitigation; no target-outcome tuning or replacement. Primary metric is equal-trial MSE in flexion², equal-date average; compare mitigation against both frozen and direct15 with the same 5%/all-date/block-interval rule. These are repeated sessions in one animal, not independent-subject generalization.

If no genuinely uninspected eligible corpus exists, independent validation is BLOCKED by access/history, not relabeled earlier data. If no mitigation passes development, leave eligible new sessions unscored and explicitly report validation **not executed because the prespecified promotion gate failed**. Audit-only finite/coverage metadata is not a decoder outcome. Stop after this mission; no additional architectures or outcomes-driven retries.
