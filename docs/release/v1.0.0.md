# CEREBRO v1.0: Adaptive Neural Intelligence Research Platform

CEREBRO provides reproducible computational neuroengineering workflows for real neural recordings, population analysis, offline decoding, representation learning, longitudinal adaptation and scientific visualization. This release packages the research platform and its evidence; it does not declare every hypothesis in the original scientific agenda successful.

## Capabilities and recorded experiments

- SENSE verifies public recording identity, checksums, units, timestamps and sampled neural coverage before producing spike counts and aligned behavior.
- MAP provides event responses, PCA/FA, condition/time-specific trial residuals, population geometry and descriptive trajectories.
- DECODE includes classical mean/linear/ridge/Kalman baselines and six modern sequence architectures, with source-only model selection and causal neural access policies.
- REMEMBER and ADAPT retain explicit session/subject identity, contact mapping, chronological calibration budgets, frozen-source/target-only/source-assisted comparisons and disclosed alignment controls.
- FOUNDATION implements masked/predictive self-supervision with matched random and supervised controls; INTERACT exposes hash-verified local results in a self-contained explorer.

The [integrated technical report](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/research/mission_020_technical_report.md) links every numerical result to experiment artifacts. Prespecified LINK low-budget source assistance did not meet its primary benefit criterion. Native Brochier four-condition classification found no clear source-assisted accuracy benefit. Brochier event-aligned population analysis used 135/142 correctly labeled, fully sampled trials with 93/156 source-designated units and documented rank limits. All negative and inconclusive results remain visible.

## Reproduction

Use the [installation guide](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/installation.md), [README quick start](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/README.md), [workflow commands](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/research/workflows.md), dataset manifests and [qualification evidence](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/release/qualification_021.md). Python 3.11 is required. Source installation with `python -m pip install -e '.[dev,classical,deep,brochier]'` exposes all documented repository workflows. Scientific training runs are CPU; public CI tests software and collects authentic-data cases separately.

## Scientific and distribution limits

- Cross-animal grip-by-load task-condition classification is not continuous movement or EMG regression. One session per Brochier animal confounds subject/session; LINK dates are repeated observations of one animal.
- FALCON targets were processed upstream of CEREBRO splits; original EMG cannot be reconstructed by inverting the published transformations. Those experiments remain exploratory.
- General subject-invariant representations, reliable high-dimensional residual covariance, broad self-supervised transfer gains and a general-purpose neural foundation model are unvalidated.
- Offline replay is not live biological closed-loop control or a clinical BCI. CUDA performance and GPU scientific equivalence are not established.
- Perich remains audit-only pending authentic neural coverage. Brochier source license texts conflict; no raw files are redistributed. See [data attribution](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/release/data_attribution.md).

The [original 33-requirement audit](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/research/full_scope_audit.json) and [updated traceability](https://github.com/adithyakupad/cerebro/blob/codex/research-platform/docs/research/mission_020_traceability.md) preserve the complete long-term scope. Source code is MIT; recordings have dataset-specific terms. No raw recording, restricted data, trained checkpoint or binary artifact is attached to this release.
