# Mission 019: frozen four-condition Brochier case study

**Observed data, not simulated:** original Brochier L/N native sorted spikes, odML trial labels and fully sampled 30 kHz raw neural blocks from [DOI 10.12751/g-node.f83565](https://doi.org/10.12751/g-node.f83565). The [protocol](../docs/research/mission_019_protocol.md) was committed as `d5fbe7f7d717d37b762d83a4f512476895adf61b` before classifier predictions were inspected. Full asset hashes and exact trial IDs, exclusions, confusion matrices, model scores and script hash are in the [machine report](mission_019_brochier_transfer.json). Acquisition and license caveats are in the [native audit](../docs/datasets/mission_019_brochier.md).

Four instructed grip-by-load conditions were classified from fourteen 20-ms spike-count bins beginning at the recorded go event. Each bin was reduced to seven anonymous population-count summaries; the fourteen bin summaries were averaged into seven features per trial. L provided 93 designated single units and 135 correct trials; N provided 156 units and 142 correct trials. The first five correct target trials per class were chronological calibration; later trials formed the untouched evaluation set. Both directions used a fixed L2 logistic baseline and train-only scaling. The independent evaluation unit was a target trial, but **not** an independent biological subject.

| Direction | Held-out target trials | Source-only balanced accuracy | Target-only | Source-assisted | Assisted − target-only; trial-bootstrap 95% interval |
|---|---:|---:|---:|---:|---:|
| L→N | 122 | 0.2500 | 0.2242 | 0.2368 | +0.0126 [−0.0616, +0.0938] |
| N→L | 115 | 0.2400 | 0.2985 | 0.3006 | +0.0021 [−0.0910, +0.0898] |

Balanced chance level and all majority-class prior baselines are 0.25. No direction shows a practically clear gain; the trial-level intervals include zero. These intervals condition on the two recorded animals and cannot estimate generalization across animals. The results do not support a claim of transferable, subject-invariant population features. The lossy anonymous seven-feature representation, short post-go interval, and small labeled calibration pool restrict the inference. The interval can include cue-related activity and does not establish decoding of actual hand movement. We did not tune the window, features, or regularization against held-out scores.

The native audit also supports **descriptive** condition-matched population analysis: all correct go windows are sampled, event ticks match source NEV, and every class has at least 30 trials in each animal. Trial-residual covariance would require explicit within-condition/event-time expectations and uncertainty, and was not run in this mission. Calibrated continuous force/displacement regression remains unsupported by unresolved physical sensor calibration. FALCON object-label classification is separately eligible as a bounded task but was not run: the Brochier native corpus provided a prospective, source-backed case study. FALCON EMG regression remains author-preprocessed and exploratory. Indy/Loco still lacks a verified Loco sampled neural timeline; Perich remains audit-only.

Reproduce locally in Conda `cerebro` after installing `python -m pip install -e '.[classical,brochier,dev]'`. From the repository root, acquire the pinned members with `python -m tools.fetch_brochier l101210-001.odml l101210-001.ns2 l101210-001.ns5 l101210-001-02.nev i140703-001.odml i140703-001.ns2 i140703-001.ns6 i140703-001-03.nev`. The acquisition script verifies every file against the [manifest](../docs/datasets/mission_019_brochier_assets.json). Run `python tools/audit_brochier.py`, then `python -m tools.run_brochier_transfer`. Raw assets stay in ignored `data/raw/brochier/`. The native and transfer JSON outputs should match the committed reports numerically; the latter records the analysis-script and manifest SHA-256. Run `python -m pytest` for software and local data checks.
